A chess engine in 4 KB of Python: rotated 120-square board, PVS alpha-beta with a transposition table, null move, late-move reductions, killers and a captures-only quiescence search, tapered piece-square tables blended at the root, a fixed node budget (deterministic) and a small per-scenario variant table.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 main.py
```
